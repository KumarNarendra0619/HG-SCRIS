## Data policy
Raw source data are not modified. Large source datasets are not committed to GitHub. The repository stores metadata, acquisition/processing scripts, configuration, samples and derived lightweight outputs where licensing permits.

## Required provenance
Every production dataset must record provider, version, acquisition date, spatial/temporal coverage, resolution, CRS, license, processing method, citation and limitations.
